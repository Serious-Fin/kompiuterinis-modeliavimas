Make a document: 5 - 10 pages
Documentation of transition to cloud computing. Based on the slides from the lectures (latest ones).

Make up some organization (school, book shop, etc). Make an analysis document on how this org transitions to cloud. 

Steps:
1. Define data (dictionary, data catalog)
2. Define services (relate them to data)
3. Define processes (relate them to services)
4. Define management (governance) (how do we manage data, services and processes from static and runtime perspective)
5. Define and assign candidates (once candidates are defined, map them to cloud computing services)
