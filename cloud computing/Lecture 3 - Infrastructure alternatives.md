Internal IT infrastructure:
- Pros - managed by the owning organization
- Cons - requires investments and continuous expenses for support

Dedicated services:
- Pros - no need to take care about IT infrastructure
- Cons - fixed not flexible fee

Advantages of cloud computing:
- Security
- Reliability
- Pay as you go
- Easy to maintain
- Easy to start and manage
- Independent from location
- Availability
- Cheaper PCs
- Higher work productivity
- Lower IT infrastructure cost
- Less support burden
- Lower software price
- Instant software update
- Increased computational power
- Unlimited storage
- Increased data security
- Increased compatibility between operating systems
- Increased compatibility of document formats
- Easier collaboration of team/group members
- Universal access to documents
- Latest version availability
- No need to be tied to a specific device
- You are not alone if cloud provider goes down

Disadvantages of cloud computing:
- Too many projects depend on a single cloud provider
- Expensive to maintain in the long run
- Environmental concerns
- Security
- Need for constant internet/network connection
- Not much useful if internet connection is slow
- Might be slow
- Limited features
- Data might not be safe
- Dependency on service provider data security
- Long term price might be higher
- SLA for regular users
- Country politics/law on accessing remote resources in other country
- Vendor lock-in

Cloud computing should not be used due to:
- Internet features
- Increased demand on data security
- Dependent on specific software

Biggest transition barriers to go from on-premise to cloud computing:
- Technical
- Business model
- Internet speed and accessibility
- Security
- Compatibility
- Social

Edge-computing - used for expanding cloud computing services. Used in remote research labs (for example in the arctic poles) to do some specific calculations. It's like a private cloud in remote locations.

Edge-computing benefits:
- Minimal latency
- Simplified maintenance
- Cheaper cooling
- Climate conscience

Pitfalls:
- Batteries might not be sufficient to run for long
- Carving servers into protected virtual slices
- Telcos defending their home territories form local breakouts
